# @haller/supabase

Shared Supabase clients and database migrations.

## Exports

- `@haller/supabase/admin` — service role (LP1, LP2)
- `@haller/supabase/browser` — anon browser client (dashboard)
- `@haller/supabase/server` — cookie session (dashboard RSC)

## Migrations

Run `migrations/001` through `007` in order in Supabase SQL Editor.
